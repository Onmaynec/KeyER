# Changelog

## v0.6.0 — KeyER Studio / Interface Redesign

### Главное окно
- Полностью переработан интерфейс WinForms: боковая навигация Text/Code, заголовок режима, новая рабочая область, панель профиля и крупная нижняя консоль Start / Pause / Stop.
- Добавлены собственные StudioButton, StudioCard и StudioProgress со скруглением, понятными состояниями наведения, нажатия, отключения и клавиатурного фокуса.
- Тёмная и светлая темы, выбор системной темы Windows, четыре акцента (Iris, Ocean, Mint, Amber).
- Компактный режим, закрепление поверх окон, запоминание размера окна.
- Адаптация команд при небольшом окне: основные действия остаются доступными, второстепенные скрываются при недостатке места.
- Новая оригинальная иконка KeyER для окна и панели задач.

### Редактор
- TextBox заменён на RichTextBox с моноширинным шрифтом, удобными отступами и постоянными метриками (символы, слова, Ln/Col).
- Добавлены номера строк и выделение номера текущей строки без изменения набираемого текста.
- Лексическая подсветка синтаксиса кода с разными цветами для ключевых слов, строк, комментариев, чисел и операторов.
- Подсветка отложена на 290 мс и отключается для больших документов (более 90 тысяч символов).
- Поиск по тексту: Ctrl+F, Enter/Shift+Enter, Esc; быстрые действия «Вставить», «Файл», «Копия», «Очистить».
- Прогресс набора показывается собственной полосой и процентом, а состояние доступно в нижней панели.

### Настройки
- Полностью переработано окно настроек: «Поведение», «Обычный текст», «Режим Code», «Горячие клавиши», «Оформление».
- В «Оформлении» регулируются тема, акцент, компактность, поверх окон, номера строк, подсветка кода и размер шрифта.
- Сохранены действующие профили, хоткеи и интеграции VS Code/Visual Studio.
- Новые параметры интерфейса хранятся отдельно от профиля скорости/ошибок в settings.json.

### Проверки
- Добавлены тесты палитры, валидации новых настроек и фактического создания WinForms UI в STA-потоке.
- GitHub Actions дополнен опциональным созданием настоящих изображений интерфейса для визуальной проверки.
- Прежние регрессионные тесты Human Behavior, Code Intelligence и IDE Integration сохранены.

### Ограничения
- Визуальная проверка через CI не заменяет проверку на реальном ПК с Windows 10/11 и разным DPI.
- Подсветка лексическая, а не полноценная IDE. Для больших документов отключается.
- Не все сторонние редакторы одинаково обрабатывают синтетические нажатия; v0.6.0 не меняет эти гарантии.


## v0.5.0 — Human Behavior 2.0

### Стили поведения
- Добавлены режимы Beginner, Casual, Developer, Professional и Custom.
- Выбор стиля автоматически применяет стартовые скорости, разброс, вероятность опечаток, привычки исправлений, продолжительность концентрации, вероятность пауз на обдумывание и просмотра текста.
- При обновлении добавляются готовые профили четырёх стилей, при этом пользовательские настройки сохраняются.
- Custom не меняет параметры профиля; значения остальных стилей после применения также можно корректировать вручную.

### Естественная работа
- Добавлена модель фокуса и частичного восстановления после перерывов. Скорость плавно следует за меняющимися периодами концентрации.
- Длительность периодов внимания, вероятность и продолжительность перерывов, вероятность обдумывания и просмотра текста настраиваются отдельно.
- В Text можно ненадолго вернуться курсором к концу только что напечатанного обычного слова, затем восстановить позицию.
- В Code аналогичный просмотр выполняется только для простых идентификаторов; перед функциями, классами и ветвлениями могут возникать дополнительные паузы.
- Все жесты не удаляют символов и ограничены понятными для клавиатуры границами. При отложенной опечатке просмотр не выполняется до исправления ошибки.

### Тестирование и совместимость
- Добавлены тесты воспроизводимости фокуса и восстановления, миграции профилей и 400 запусков с различными стилями, опечатками и перемещением курсора.
- Text 2.0, Code Intelligence, Windows горячие клавиши и IDE Integration v0.4 остаются доступны.
- Успешный виртуальный тест не заменяет проверку на реальном редакторе. Разные IDE могут обрабатывать клавиши и автодополнение по-разному.


## v0.4.0 — IDE Integration

### VS Code
- Добавлено отдельное локальное расширение VS Code (VSIX) с Windows Named Pipe для связи с KeyER. Соединение ограничено текущим пользователем и уровнем привилегий.
- Перед проверяемым вводом расширение подтверждает, что активен пустой текстовый документ, выделений нет и установлен один курсор в начале.
- Расширение читает параметры автоскобок, автокавычек, автоотступов, форматирования и табуляции, не изменяя пользовательские настройки.
- При переключении вкладки, закрытии документа или потере фокуса отправляется сигнал об остановке набора.
- После физического ввода расширение сравнивает текст с исходником. По явной настройке возможно исправление расхождения через API TextEditor.edit; сохранение на диск не выполняется.
- Проверяемый режим ограничен 250 000 символами; непустые файлы сознательно не допускаются к автоматическому исправлению.

### Visual Studio
- Добавлен экспериментальный адаптер COM/DTE для поиска активного экземпляра Visual Studio 2022 по PID.
- Подтверждение пустого текстового документа, отслеживание его активности, сравнение результата; исправление через DTE только по отдельному разрешению.
- Если IDE не поддерживает автоматизацию или доступ заблокирован, проверяемый набор не запускается вместо ложного сообщения об успехе.

### Управление, тесты, сборка
- В Code-профиле появился выбор: обычный набор, только проверка, проверка с исправлением. По умолчанию интеграция отключена — предыдущие сценарии сохранены.
- В движке введён результат выполнения (completed, cancelled, focus lost, failed), чтобы исключить проверку незавершённого набора.
- Добавлен тест Windows Named Pipe и тесты VS Code extension с виртуальным редактором.
- GitHub Actions дополнен проверкой расширения Node.js и созданием артефакта VSIX рядом с Portable и установщиком.
- Подготовлена документация по установке и ограничениям.

### Ограничения
- Интеграция подтверждает или исправляет **итоговый текст**, но не гарантирует идеальную промежуточную работу с IntelliSense.
- Настоящие GUI-тесты в Visual Studio и VS Code не входят в CI. Работа DTE может отличаться в разных установках.
- Исправление выполняется через API редактора, а не только клавиатурой. Это явно опциональная операция и не сохраняет файл.


## v0.3.0 — Code Intelligence

### Новое
- Code теперь использует отдельные лексический планировщик и движок: комментарии, строковые литералы, ключевые слова, идентификаторы, числа, операции, границы блоков и отступы.
- Поддержано распознавание 20 языков по расширению файла и эвристикам; в основном окне добавлен ручной выбор языка с приоритетом над автоопределением.
- Планировщик различает импорт, классы, функции, ветвления, возвраты, объявления, комментарии и обычные строки.
- Новые параметры Code: паузы перед функциями, блоками, строками и синтаксисом; отдельная скорость для идентификаторов, строк и комментариев.
- Реалистичные ошибки Code ограничены идентификаторами и ключевыми словами; они исправляются до дальнейшего ввода.
- Опциональное выделение и повторный набор 1–3 последних букв имени через Shift+Left. По умолчанию выключено.
- Существующие настройки и режим Text v0.2 сохранены.

### Тестирование
- Регрессионные тесты сохранения исходного кода после токенизации по 15 примерам разных языков.
- Проверка состояний строк, многострочных комментариев, Python triple quotes и игнорирования скобок внутри комментариев.
- Несколько сотен проверок набора кода с опечатками и исправлениями в виртуальном редакторе.
- Контекстные паузы и ручной выбор языка покрыты автоматическими тестами.

### Ограничения
- Лексический анализатор не является полноценным AST и не проверяет семантику/компиляцию.
- Внешние настройки IntelliSense, автоскобок и автоотступов пока не читаются. Полная интеграция с Visual Studio и VS Code запланирована на v0.4.0.
- Реальная проверка в IDE требуется отдельно; виртуальные тесты не могут гарантировать точность в конкретной IDE.


## v0.2.0 — Human Typing Engine

### Text: естественная скорость
- Для Text создан отдельный движок, изолированный от Code.
- Добавлены отдельные множители темпа для коротких и длинных слов.
- Замедление на цифрах, пунктуации и специальных символах; ускорение на распространённых буквосочетаниях.
- Плавное сглаживание задержки, периоды более быстрого набора, случайные колебания и усталость.
- Паузы после предложений, между абзацами и длинные перерывы между блоками.

### Text: опечатки и коррекции
- Подмена соседней клавишей, пропуск, дублирование и перестановка букв.
- Возврат к ошибкам спустя несколько слов в пределах безопасной текстовой строки.
- Исправления Backspace, Delete либо выделением Shift+Left; возврат курсора на прежнюю позицию.
- Настраиваемая доля стратегий исправления и лимиты запоздалого исправления.
- Возможность отключить ошибки (0%) без отключения естественного темпа.

### Текстовые поля и профили
- Настраиваемые Enter / Shift+Enter и Tab / 1–8 пробелов.
- Пресеты «Обычный текст» и «Переписка».
- Однократная миграция профилей старых версий без потери пользовательских настроек.
- В основном окне отображается выбранный способ переноса строки и табуляции.

### Проверки и ограничения
- Детерминированные проверки точности с виртуальным редактором и сотнями сценариев исправлений.
- Проверка Unicode, списков, абзацев, длинных ошибок, Shift+Enter, табуляции и временных интервалов.
- Универсальное точное воспроизведение в любом внешнем приложении **не гарантируется**; поле может обрабатывать Enter, Tab и выделения по-своему. Реальные GUI-тесты остаются обязательными.


## v0.1.1 — Stability Hotfix

### Исправлено
- Глобальные сочетания Ctrl+Alt+F5 / F6 / F7 больше не требуют случайно добавленной клавиши Win: неверное битовое сравнение Keys.LWin устранено.
- Старт набора ждёт отпускания Ctrl, Alt, Shift и Win, чтобы не вводить символы под удерживаемыми модификаторами.
- Целевое активное окно проверяется перед каждым событием ввода, в том числе при перемещении курсора и исправлении ошибок.
- Исправлена логика отложенного исправления переставленных букв.
- В Text опасный переход Home/End заменён обратимой парой Left/Right.
- При частичной доставке Win32 SendInput выполняется попытка отпустить уже нажатые клавиши.
- Настройки сохраняются атомарно с резервной копией и восстановлением при повреждении основной версии.
- Проверяются значения профилей, режимов и горячих клавиш при загрузке.
- Ошибки пишутся в локальный диагностический журнал без исходного текста, заголовков окон и путей файлов.

### Тесты и сборка
- Добавлен тестовый адаптер, симулирующий ввод в памяти без реальных нажатий.
- В CI проверяются Unicode, табуляции и переносы, исправление опечаток на 100 детерминированных последовательностях, смена активного окна, пауза, остановка и сочетания клавиш.
- Для Windows собираются Portable и установщик Inno Setup.

### Ограничения
- Ручное end-to-end тестирование в реальных окнах Windows обязательно для подтверждения совместимости.
- Code по-прежнему не интегрирован напрямую с IntelliSense, автозакрытием скобок или внутренним состоянием Visual Studio и VS Code.
- Некоторые приложения могут игнорировать синтетический ввод.

## v0.1.0 — Foundation
- Начальный редактор с режимами Text и Code, профилями, настраиваемыми горячими клавишами.
- Первый движок набора с ошибками и исправлениями, Win32 SendInput, portable и установщик.
