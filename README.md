# KeyER

**KeyER** — настольное приложение для Windows 10/11: набирает подготовленный текст в активном окне через события клавиатуры, имитируя скорость, паузы, опечатки и их исправление.

**Новое в v0.6.0:** интерфейс KeyER Studio полностью переработан. Вместо простого многострочного поля — цельное рабочее пространство с боковой навигацией, новым редактором, поиском, подсветкой кода, номерами строк, крупными управляющими кнопками и аккуратным отображением прогресса. Доступны тёмная и светлая темы, автоматическое соответствие теме Windows, четыре акцента и компактная компоновка.

## Возможности v0.6.0 — KeyER Studio (Interface Redesign)

- **Text 2.0**: естественный набор с плавной скоростью, быстрыми знакомыми сочетаниями букв, отдельным темпом для коротких и длинных слов, паузами после предложений, абзацев и между блоками текста.
- Ошибки в Text: пропуск, замена соседней клавишей, повтор и перестановка букв; немедленные исправления и возврат спустя несколько слов через Backspace, Delete, Shift+Left и стрелки.
- Настраиваемая обработка Enter (Enter либо Shift+Enter) и Tab (физическая клавиша либо 1–8 пробелов). Профиль «Переписка» использует Shift+Enter.
- Готовые профили «Обычный текст» и «Переписка», а также поддержка миграции 0.1.x с сохранением собственных профилей.
- **Интерфейс Studio v0.6:** боковая панель Text / Code, выбор текущего профиля, быстрые переключатели темы, компактного режима и закрепления окна; собственная иконка приложения.
- **Редактор:** RichTextBox с номерами строк и позициями Ln/Col, цветной лексической подсветкой кода, поиском (Ctrl+F), быстрыми действиями «Вставить», «Файл», «Копия», «Очистить» и счётчиком символов и слов.
- **Управление вводом:** крупные кнопки «Начать», «Пауза», «Стоп», собственная шкала прогресса и статус. На узком окне элементы адаптируются, менее важные команды скрываются.
- **Настройки:** отдельные разделы «Поведение», «Обычный текст», «Режим Code», «Горячие клавиши», «Оформление». Внешний вид не хранится внутри профиля набора.
- **Оформление:** Dark / Light / System; акценты Iris, Ocean, Mint, Amber; настройка размера шрифта, подсветки синтаксиса и номеров строк. Параметры сохраняются автоматически в settings.json.
- **IDE Integration v0.4**: проверка итогового кода в VS Code через локальное расширение и в Visual Studio через DTE. Проверяемые сессии требуют пустой документ и один курсор в начале. Возможны режимы «Только проверить» и «Проверить и исправить», а также обычный ввод без интеграции.
- Расширение VS Code сообщает настройки автозакрытия скобок, автокавычек, автоотступов и форматирования. При смене вкладки или окна отменяет сессию; исходный код не отправляется в интернет. Исправление по явному выбору выполняется через API редактора **только после** имитации клавиатурного набора.
- Visual Studio 2022: экспериментальная проверка пустого документа через DTE/COM с подбором экземпляра по PID и проверкой активного документа.
- **Code 0.3**: отдельный лексический анализатор с выбором языка, отслеживанием комментариев, строк и вложенности блоков. Планирование набора функций, классов, импортов, управляющих конструкций, переменных, комментариев и обычных строк.
- Для Code — настраиваемые паузы перед функциями/классами и блоками, темп печати идентификаторов, строк и комментариев; ошибки только внутри ключевых слов и имён, с обязательным исправлением. По желанию — безопасное локальное выделение окончания идентификатора через Shift+Left и повторный набор.
- Поддерживается определение 20 языков по расширению; для фрагментов без файла — эвристики; язык можно выбрать вручную в главном окне.
- Набор Unicode-символов (английский, русский и другие языки), переводов строк и табуляций.
- Случайная скорость, серии быстрого набора, редкие паузы, усталость и четыре типа исправляемых ошибок: подмена, пропуск, повтор, перестановка символов.
- Исправление после нескольких последующих символов при помощи стрелок, Backspace и повторного набора.
- Настраиваемые **глобальные** горячие клавиши старта, паузы и остановки.
- Предустановленные и пользовательские профили; настройки сохраняются в `%LOCALAPPDATA%\KeyER\settings.json`.
- Проверка целевого окна перед каждым вводимым действием и остановка при смене фокуса.
- Набор начинается после отпускания модификаторов глобального хоткея; Ctrl+Alt+F5/F6/F7 не требуют клавиши Win.
- Безопасный симметричный жест проверки курсора вместо Home/End.
- Атомарная запись настроек с резервной копией и восстановлением.
- Диагностика в %LOCALAPPDATA%\KeyER\diagnostics.log без записей набираемого текста, названия окна и имён файлов.
- Переносной EXE и установщик Windows из GitHub Actions (Inno Setup).

## Запуск из исходников

Установите [**.NET 8 SDK**](https://dotnet.microsoft.com/download/dotnet/8.0) на Windows 10/11.

```powershell
dotnet run --project src/KeyER/KeyER.csproj -c Release
```

Или опубликуйте portable-сборку:

```powershell
dotnet publish src/KeyER/KeyER.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None -o dist/KeyER
```

Для Portable ZIP, установщика и VS Code VSIX см. вкладку **Actions** → **Windows build** → **Artifacts**; в репозитории нет заранее собранных бинарников.

## Проверяемый Code в VS Code / Visual Studio

1. **VS Code:** установите артефакт `KeyER-VSCode-0.5.0.vsix` через меню Extensions → ... → Install from VSIX. Расширение локальное и работает только в настольном редакторе Windows.
2. **Visual Studio 2022:** дополнительное расширение не требуется — KeyER пробует подключиться к автоматизации DTE/COM активной IDE. Это экспериментальный адаптер; он может не работать в некоторых конфигурациях.
3. Откройте **новый пустой текстовый документ** в IDE и поставьте единственный курсор в начало.
4. В KeyER выберите **Code → Настройки профиля → IDE: проверка итогового кода**. Для автоматического исправления установите «Проверить и исправить».
5. Перейдите в окно IDE и нажмите Ctrl+Alt+F5. В конце KeyER сравнит результат с исходным кодом и сообщит, совпал ли он. Исправление выполняется только в режиме «Проверить и исправить» и **не сохраняет файл на диск**.

При отключённой проверке продолжается прежний режим реальных событий клавиатуры. Если включена проверка, но редактор не подключён или файл не пустой, KeyER **не начинает** набор, чтобы не обещать неподтверждённую точность.

Подробнее: [интеграция IDE](docs/IDE_INTEGRATION.md) и [расширение VS Code](extensions/vscode/README.md).

## Управление рабочим пространством

- Слева выберите **Text** или **Code** и профиль набора. В Code над редактором появляется выбор языка.
- Команды над редактором: вставка текста, импорт файла, копирование и очистка. **Ctrl+F** открывает поиск по исходнику, Enter — следующее совпадение, Shift+Enter — предыдущее, Esc — закрыть.
- Внизу расположены запуск, пауза и остановка, а также прогресс и настроенные горячие клавиши.
- В левой панели можно быстро переключить тему, компактность интерфейса и режим поверх других окон.
- В «Настройках» → «Оформление» можно выбрать тему Windows, цветовой акцент, размер шрифта, номера строк и подсветку кода.
- Размеры окна сохраняются при изменении размера вручную. Даже в компактном режиме окно остаётся масштабируемым.

Описание устройства UI, ограничений и управления цветом: [docs/UI_DESIGN.md](docs/UI_DESIGN.md).

## Быстрый старт

1. Вставьте текст или код в окно KeyER; выберите **Text** или **Code** и профиль.
2. Откройте целевое приложение и поставьте курсор в нужное место.
3. Нажмите **Ctrl+Alt+F5** для старта (либо кнопку «Начать» в KeyER и переключитесь в целевое окно за время отсчёта).
4. **Ctrl+Alt+F6** — пауза/продолжить; **Ctrl+Alt+F7** — остановить. Все сочетания настраиваются.
5. Во время набора не печатайте вручную в целевом окне, иначе результат может отличаться.

## Важные ограничения

KeyER не использует буфер обмена для вывода. Для ввода применяется Win32 `SendInput` с Unicode-событиями. Это не гарантирует совместимость с *каждым* приложением: некоторые поля, игры, терминалы и привилегированные окна блокируют синтетический ввод. Запуск KeyER без прав администратора не позволяет вводить данные в приложение, запущенное с повышенными правами (UIPI).

**Важно для Text:** в обычных текстовых полях Tab может переключать фокус, а Enter в мессенджере может отправить сообщение. Для Telegram и подобных чатов выбирайте профиль «Переписка» (Shift+Enter) и заранее проверяйте поведение поля ввода. Вывод не считывается обратно из чужой программы, поэтому KeyER не подтверждает побайтовое совпадение введённого текста в каждом приложении. При выборе «Пробелы вместо Tab» итог намеренно отличается от оригинального символа табуляции.

**Code** анализирует текст лексически и может проверить результат в поддерживаемых IDE, если включена опциональная интеграция. Обычная эмуляция не имеет доступа к содержимому чужого редактора. Даже с интеграцией автозамены и плагины могут менять текст после проверки; режим «Проверить и исправить» исправляет содержимое пустого документа через IDE API в конце набора, но не гарантирует точность промежуточных экранных действий. В других программах, в непустых документах и при выключенной интеграции точное совпадение не подтверждается. «Очистка автоотступа» экспериментальная.

Управляющие последовательности и хоткеи не предназначены для обхода ограничений приложений. Используйте программу только в собственных окнах/с разрешения владельца.
