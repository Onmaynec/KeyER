# KeyER Studio — Interface Redesign v0.6.0

## Что изменилось

Вместо простого WinForms TextBox KeyER использует полноценное рабочее пространство **KeyER Studio**. Все визуальные компоненты написаны на C# и System.Windows.Forms; Electron, WebView, веб-серверы, сетевые шрифты и сторонние UI-библиотеки не требуются.

### Главное окно

- **Левая навигация:** оригинальный знак KeyER, переключатели Text/Code, активный профиль, быстрые настройки темы, компактного вида и закрепления поверх окон.
- **Шапка:** заголовок режима, краткое описание и команды «Поиск», «Справка», «Настройки».
- **Рабочая область:** редактор кода/текста, команды вставки, загрузки, копирования и очистки. Для Code доступен ручной выбор языка.
- **Нижняя консоль:** отдельные Start/Pause/Stop, индикация текущего состояния, собственная шкала прогресса с процентами и подсказка о горячих клавишах.

Содержимое редактора не теряется при смене темы или переходе между Text/Code. При работающем наборе управление настройками и редактированием исходника блокируется, пока не завершится сессия.

### Цветовые темы

Theme реализован как статическая палитра, от которой зависят все цвета оформления. Доступны:

- **Dark:** глубокая графитово-синяя основа, светлый текст, приглушённые границы.
- **Light:** светлый нейтральный фон, контрастный тёмный текст и мягкие разделители.
- **System:** чтение параметра AppsUseLightTheme из настроек Windows при построении интерфейса.

Акцентные палитры **Iris** (фиолетовая), **Ocean** (синяя), **Mint** (мятная), **Amber** (янтарная) меняют выделенные элементы и управляющие кнопки. Новое оформление сохраняется в AppSettings, а сам набор не зависит от темы.

### Компоненты

- StudioButton — круглённые кнопки с hover/pressed/focus/disabled состояниями, отрисовкой через GDI+, сохранением стандартных нажатий клавиатуры.
- StudioCard — панели со скруглением и тонкой границей.
- StudioProgress — собственная шкала прогресса, не зависящая от стандартного Windows ProgressBar.
- EditorGutter — номера строк и подсветка активной строки; он не изменяет содержимое редактора.
- SyntaxPainter — подсветка синтаксиса на базе существующего CodeAnalyzer, с задержкой перерисовки 290 мс и ограничением по длине документа (90 тысяч символов), чтобы не замедлять большие файлы. Сохраняет позицию курсора и скролла.
- BrandIcon — собственная вектороподобная иконка KeyER, рисуемая программно при старте.

### Компоновка

- Главное окно: минимум 785×560 пикселей, размер сохраняется в настройках.
- Компактный режим уменьшает боковую панель, верхний заголовок и нижнюю консоль.
- При уменьшении окна некоторые второстепенные кнопки скрываются, а обязательные команды Start, Pause, Stop остаются видимыми.
- RichTextBox поддерживает стандартную работу с текстом, копирование, вставку, выделение и Undo. Цветное форматирование не влияет на исходную последовательность символов, которую получает движок набора.

## Новое окно настроек

Параметры разделены на пять экранов: **Поведение**, **Обычный текст**, **Режим Code**, **Горячие клавиши**, **Оформление**. Секция общих параметров больше не конкурирует за место с параметрами Text/Code.

Все формы работают с клонированной рабочей копией AppSettings. Нажатие **Сохранить изменения** валидирует и применяет значения; **Отмена** не должна изменять настройки. Изменение оформления через быструю кнопку сохраняется отдельно.

## Проверки

Windows CI проверяет сборку приложения и создание главного окна и настроек на выделенном STA-потоке, наличие редактора RichTextBox, панели номеров строк и кастомных элементов. Дополнительно тестируются диапазоны размера окна, корректность светлой/тёмной палитры, акцентных цветов и прежние регрессии Text/Code/IDE.

Отдельный опциональный шаг GitHub Actions пытается сформировать **реальные снимки WinForms окон**. Результат зависит от доступности GUI в Windows runner и не подменяется фейковым макетом.

## Ограничения

- Это WinForms/GDI+ UI, не WPF/WinUI. Анимации сознательно минимальны; важнее отзывчивость и надёжное управление.
- Подсветка Code — лексическая, а не анализ компилятора, особенно для сложных языковых конструкций.
- На больших исходниках подсветка отключается для предотвращения зависаний.
- Система оформления в режиме System считывает тему Windows при применении параметров; автоматическая мгновенная смена при каждом событии ОС не гарантируется.
- Размер и перенос текста в отдельных элементах зависят от системного масштабирования. Ручная проверка 100%, 125%, 150% DPI на Windows 10/11 остаётся необходимой.
- На некоторых системах без шрифта Cascadia Code Windows подставит другой моноширинный шрифт.
