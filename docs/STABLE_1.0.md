# KeyER v1.0.0 — Stable Release

KeyER 1.0.0 — стабильная версия Windows-приложения на .NET 8 WinForms. Сохранены режимы Text и Code, профили естественного набора, UI KeyER Studio и опциональная интеграция VS Code / Visual Studio.

Статус Stable означает успешное прохождение описанных ниже автоматических проверок. Он не является гарантией, что любое приложение Windows примет синтетический ввод через SendInput.

## 1. Восстановление настроек

- Сохраняется атомарная запись settings.json. Предыдущая корректная версия переносится в settings.json.bak.
- При повреждении основного JSON и наличии исправного backup KeyER загружает резервную версию.
- Следующее сохранение **не заменяет корректный backup повреждённым файлом**. Нечитаемый основной файл копируется в settings.json.corrupt-<timestamp>-<random> в приватной папке LocalAppData, затем заменяется новым.
- При двух повреждённых файлах KeyER показывает предупреждение, использует стандартные значения и сохраняет старый основной JSON отдельно перед его заменой.
- Файлы настроек размером более 4 MiB не загружаются. Это ограничение не распространяется на документы.
- Проверена миграция с предыдущих схем без потери пользовательских профилей, выбора профиля, настроек скорости и поведения.

Путь: %LOCALAPPDATA%\KeyER\settings.json. Повреждённые архивы могут содержать пользовательские параметры — не публикуйте их без проверки.

## 2. Горячие клавиши

- Старт, пауза и стоп регистрируются как один согласованный набор.
- Изменение цвета интерфейса или любого другого параметра без смены горячих клавиш больше не вызывает снятие и повторную регистрацию рабочих клавиш.
- При попытке установить занятое сочетание KeyER отклоняет изменение и пытается восстановить прежний рабочий набор.
- Дублирующиеся сочетания не изменяют работающие горячие клавиши.
- При закрытии процесса клавиши освобождаются.

## 3. Отмена набора и корректность

При нажатии Stop во время обратного отсчёта или ожидания ответа IDE KeyER проверяет отмену непосредственно перед передачей текста движку ввода. Отменённый старт не должен возобновляться после асинхронной операции.

Сохранены проверки HWND/PID, смены фокуса, необычных удерживаемых клавиш-модификаторов, безопасная пауза и остановка. Отчёт об обработанных символах не означает подтверждённое содержимое чужого документа.

## 4. Диагностика и приватность

- Настройки → Диагностика показывает техническую сводку с заголовком KeyER Studio — support report.
- Экспорт теперь предлагает имя KeyER-diagnostics.txt вместо бета-имени.
- Отчёты существуют локально и передаются только вручную.
- Исходные тексты, пути файлов, имена пользователя, заголовки чужих окон и сообщения исключений в отчёты не включаются.

## 5. Состав поставки

- Windows x64 установщик KeyER-v1.0.0-Setup.exe.
- Самодостаточный Portable ZIP KeyER-v1.0.0-portable-win-x64.zip.
- Локальное расширение VS Code KeyER-VSCode-1.0.0.vsix.
- Файл SHA-256 для проверки скачанных артефактов.
- Исходники, changelog, тесты и документация в GitHub.

Инсталлятор работает без обязательных административных прав. Коммерческой цифровой подписи нет.

## 6. Критерии качества

Windows GitHub Actions выполняет сборку с предупреждениями как ошибками, регрессии Text/Code/Human/IDE, тесты отката хоткеев и восстановления настроек, тесты ранней отмены, а также 270 дополнительных детерминированных сессий Text/Code с несколькими стилями печати.

**Генерация настоящих снимков WinForms-интерфейса стала обязательной** частью сборки, а не опциональной. Также проверяется расширение VS Code и создаётся SHA256SUMS.

## 7. Приёмка на настоящем ПК с Windows

1. Установить KeyER и проверить запуск и блокировку второго экземпляра.
2. Сравнить настройки и пользовательские профили после обновления с v0.9.
3. Использовать копию settings.json и settings.json.bak для проверки восстановления из повреждённого основного файла.
4. Настроить занятое другой программой сочетание, убедиться в восстановлении предыдущих горячих клавиш.
5. Отменить начало набора в Countdown и IDE preflight; проверить отсутствие дальнейшего ввода.
6. Протестировать полный набор, Stop, Pause, потерю фокуса в Блокноте, VS Code и Visual Studio.
7. Повторить сохранение Unicode-документа и проверить содержимое и отсутствие временных файлов.
8. Проверить DPI 100%, 125%, 150%, минимальный размер окна и клавиатурную доступность настроек.
9. Экспортировать локальный отчёт только вручную и проверить отсутствие конфиденциальной информации.
10. Сверить SHA-256 установщика, Portable и VSIX с контрольным файлом из той же сборки CI.

## Известные ограничения

- Приём SendInput зависит от конкретного редактора, UAC и настроек Windows; гарантировать совместимость со всеми полями невозможно.
- Точное совпадение результата можно проверять лишь в поддерживаемых IDE и при включённой проверке.
- Нужны ручные проверки DPI, реальных действий клавиатуры, многомониторной конфигурации и долгих сеансов.
- Нет автоматических обновлений, телеметрии, платного API и облачных сервисов.
