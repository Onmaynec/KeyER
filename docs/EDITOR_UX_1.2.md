# KeyER v1.2.0 — Editor & UI Overhaul

Обновление основано на реальных снимках пользовательского окна KeyER v1.1.0: слишком большое пустое поле, неудобное открытие/сохранение файлов, системные красные выделения в выпадающих списках, скачки прокрутки при синтаксической подсветке и серо-синяя тёмная палитра.

## 1. Исправлен скачок редактора при подсветке

Первопричина: обновление синтаксиса RichTextBox использует операции выделения фрагментов и изменение SelectionColor. При каждой перекраске RichEdit может переместить курсор, изменить вертикальную/горизонтальную прокрутку, а повторный запрос из статистики мог перезапустить таймер подсветки.

В версии 1.2.0:
- **SyntaxPainter** хранит последнюю успешно оформленную версию текста и параметры оформления. Повторный запрос с *тем же* текстом, языком, темой и режимом не выполняет перекраску.
- Повторные запросы одного и того же изменения больше не перезапускают таймер ожидания: подсветка происходит после 290 мс покоя, а не через чередующиеся таймеры статистики.
- До и после прохода запоминаются и восстанавливаются выделение пользователя, вертикальная **и** горизонтальная позиция RichEdit в пикселях.
- Перекраска выполняется при подавленной отрисовке и завершается единственным обновлением экрана.
- Отдельно отключён нативный spell-check RichEdit (IMF_SPELLCHECKING), чтобы красные подчёркивания не конкурировали с подсветкой кода. Работа IME и обычного ввода сохраняется.
- Для исходников свыше 90 тысяч символов подробная подсветка пропускается, но стандартный цвет текста остаётся корректным.

**Проверка:** после открытия кода прокрутить вниз, не печатать несколько секунд — экран не должен прыгать. Затем изменить одну строку: должна произойти одна перекраска без изменения положения курсора и прокрутки. При смене темы/языка одна осознанная повторная перекраска допустима.

## 2. Новый чёрно-белый Dark

Тёмная тема теперь не серо-синяя:
- фон приложения #000000;
- поверхность боковой панели и карточек #0A0A0A;
- поле редактора #050505;
- слегка приподнятые элементы #161616;
- разделители #313131;
- основной текст почти белый #FAFAFA;
- активные кнопки/навигация с **белой** заливкой и **чёрным** текстом.

Светлая тема не переработана: сохранены прежние светлые фоны и цветные акценты. В тёмной теме смысловые статусы (предупреждения/ошибки) и синтаксис кода могут быть цветными для понимания событий и чтения кода, но фоны и навигация остаются чёрно-белыми.

«Как в Windows» автоматически выбирает соответствующую палитру. Предпросмотр темы в настройках теперь показывает настоящую чёрно-белую версию.

## 3. Оформленные выпадающие списки

Поле профиля, выбор языка и списки в настройках переведены на owner-draw ComboBox:
- темное/светлое оформление закрытого поля и раскрытого списка;
- светлое выделение с чёрным текстом в тёмной теме, цветное выделение в светлой;
- увеличенная высота строк, отступы и автоматическая ширина раскрытого списка;
- сохранены обычная клавиатурная навигация и выбор элемента.

Внешняя рамка системного списка может зависеть от Windows, однако красный системный фон выбранной строки больше не должен использоваться.

## 4. Рабочее пространство удобнее

**F11 — фокус редактора.** Скрывает левую панель, отдавая всю доступную ширину коду. Строка Start/Pause/Stop остаётся на экране, чтобы пользователь всегда мог остановить ввод. F11 возвращает обычный вид; кнопка переключения находится в шапке.

**Alt+Z — перенос длинных строк.** В обычном режиме длинные строки имеют горизонтальную полосу прокрутки — больше нет обрезанного текста без возможности дойти до начала или конца строки. В режиме переноса горизонтальная прокрутка отключается. Это только изменение представления, содержимое и undo-история не меняются.

В широком окне кнопки «Перенос» и «Строки» доступны рядом с выбором языка. Номера строк можно показать/скрыть, настройка сохраняется. Фокус/перенос можно переключать клавиатурой независимо от ширины окна.

Добавлены более компактные рабочие отступы, адаптивная шапка и полностью русская подпись пространства. Пустая область поддерживает перетаскивание одного текстового файла, даже когда экран приглашения перекрывает редактор.

## 5. Исправлено сохранение и индикация

- **Ctrl+S:** если уже открыт файл, сохраняет изменения прямо в него через безопасную атомарную замену. Если открыт новый фрагмент без пути, появляется Save As.
- **Ctrl+Shift+S:** всегда спрашивает имя и папку (Save As).
- **Ctrl+O:** открыть исходный текст.
- При очистке, открытии или редактировании нового исходника старое значение прогресса (например 17,8%) сбрасывается в 0%. Старый отчёт о сеансе по-прежнему можно посмотреть вручную.
- Встроенный редактор сохраняет Unicode и прежнюю опциональную проверку Code/IDE.

## 6. Контроль качества

Windows CI должен успешно проверить:
- отсутствие повторных проходов SyntaxPainter без изменения текста;
- сохранение позиции курсора и видимой области при одном проходе подсветки;
- повторную подсветку строго после реального изменения документа;
- чёрно-белый Dark и **неизменённый** Light;
- owner-draw выделение ComboBox;
- F11, Alt+Z, горизонтальную прокрутку и неизменность текста;
- Ctrl+S без диалога для уже открытого документа;
- предыдущие регрессии Text, Code, Humanizer 3.0 и IDE Integration;
- настоящие WinForms-снимки основного интерфейса, настроек и фокус-режима;
- финальный Setup, Portable, VSIX и SHA-256.

Автотесты не доказывают абсолютную работоспособность каждого стороннего редактора Windows. Требуется пользовательская проверка длинного кода, горизонтального скролла, многомониторной конфигурации и DPI (100%, 125%, 150%).

## Короткие команды

| Команда | Действие |
| --- | --- |
| Ctrl+O | Открыть файл |
| Ctrl+S | Сохранить текущий файл |
| Ctrl+Shift+S | Сохранить как |
| Ctrl+F | Поиск |
| F11 | Показать/скрыть боковую панель, фокус |
| Alt+Z | Перенос длинных строк |
| Ctrl+Alt+F5 (по умолчанию) | Начать набор |
| Ctrl+Alt+F6 | Пауза |
| Ctrl+Alt+F7 | Остановить |

Глобальные команды могут быть изменены в настройках. Выбор исходного файла сам по себе **не запускает ввод**.
