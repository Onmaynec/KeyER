# KeyER — расширение VS Code (v0.6.0)

Локальное расширение для проверки клавиатурного набора в **пустом текстовом редакторе** VS Code.

- Работает только в настольном VS Code под Windows.
- При запуске соединяется с KeyER через канал Windows Named Pipe `\\.\pipe\KeyER.IdeBridge.v1`. Сервер допускает только процессы того же пользователя Windows и того же уровня привилегий.
- **Не** передаёт код в сеть и не сохраняет его в логи.
- Перед началом сессии требует, чтобы редактор был пустым, курсор стоял в начале, не было выделений/дополнительных курсоров.
- Сообщает KeyER настройки автоскобок, автокавычек, автоотступа и форматирования.
- Во время набора отслеживает переключение редактора или окна; сообщает KeyER об отмене.
- В конце сессии сравнивает фактический текст с исходным и **по выбранному режиму** исправляет расхождения через VS Code TextEditor API, не сохраняя документ на диск. Это единственный шаг, где может использоваться API редактирования вместо клавиатуры — с целью гарантировать корректность результата.
- Не управляет IntelliSense по клавиатуре, не отключает пользовательские настройки VS Code и не отправляет содержимое документов из других вкладок.

## Установка

Откройте VS Code → Extensions → меню `...` → **Install from VSIX** → выберите `KeyER-VSCode-0.6.0.vsix` из артефактов сборки. Перезапустите VS Code. Запустите KeyER.

Если расширение не подключилось, проверьте команду `KeyER: Connection status` через Command Palette и убедитесь, что KeyER и VS Code запущены от одного пользователя и на одном уровне привилегий.

## Как проверить

1. В KeyER выберите Code и в настройках профиля — «Проверять и исправлять (пустой документ)».
2. В VS Code создайте **новый пустой файл**, поставьте один курсор в начало.
3. Запустите набор глобальной клавишей Ctrl+Alt+F5, не переключая окно.
4. После завершения в статусе KeyER появится результат проверки/исправления.

Режим «Только проверять» сообщает о расхождении, но **не меняет** содержимое редактора. Режим «Отключено» запускает обычную эмуляцию клавиатуры без связи с расширением.

**Предупреждение:** автозамены других расширений могут изменить документ уже после проверки. Промежуточный визуальный набор может быть неидеальным при включённом IntelliSense; окончательная корректность обеспечивается контролируемой сверкой и разрешённым исправлением.
